## 📄 4. 메인 콘텐츠 (Main Content View)

사용자가 선택한 네비게이션 탭에 따라 메인 영역이 전환됩니다.

### 4.1. 메인 페이지 (`Button_1` 선택 시)
- 화면 중앙에 마우스 대표 이미지배치.
- **인터랙션**: 마우스 호버(`hover`) 시 이미지 크기가 커지는 `zoom-in / scale-up` 효과 적용.

### 4.2. 기능 소개 페이지 (`Button_2` 선택 시)
제품(M585/M590 Silent)의 핵심 기능 및 소프트웨어 맵핑 안내 페이지.

#### ⚙️ 제품 주요 스펙 및 하드웨어 기능
1. **Easy-Switch™ 버튼 & LED**
   - 최대 2개 기기(컴퓨터, 태블릿 등)까지 간편하게 스위칭 가능.
   - 상단 번호 표시등(1, 2) LED를 통해 현재 연결 채널 확인.
2. **커스텀 측면 버튼**
   - 좌측 2개 버튼(앞으로 가기 / 뒤로 가기) 제공, 소프트웨어를 통해 기능 재맵핑 가능.
3. **전원 콘트롤**
   - 하단 On/Off 슬라이드 스위치 적용으로 효율적인 배터리 관리.
4. **휠 & 틸트 버튼**
   - 초정밀 스크롤 휠 및 좌우 틸트(Tilt) 기능 지원.
5. **Unifying™ USB 수신기**
   - 초소형 무선 수신기 제공 (하단 배터리 슬롯 내부에 보관 가능, 최대 6대 기기 다중 연결 지원).

#### 🛠️ 커스텀 기능 맵핑 (logi Options+ 소프트웨어)
- **기본 설정**: 앞으로 가기, 뒤로 가기
- **권장 옵션**: 복사/붙여넣기, 화면 확대/축소, 볼륨 조절 등
- **사용 가능한 기능 옵션**:
  - 계산기 실행, 다시 실행(Redo), 다음/이전, 새 브라우저 탭 열기, 스크린 캡처, 이모티콘 팝업, 시스템 잠금, 입력 언어 전환, 파일/폴더 열기, 미디어 재생/일시정지 등
- **Smart Actions (스마트 액션)**:
  - 사용자 지정 매크로 및 자동화 흐름 제작 기능.

#### ⚡ Smart Actions 설정 가이드
1. **If (트리거) 설정**: 특정 액션(버튼 클릭, 실행 등) 발생 조건 지정.
2. **Then (동작) 설정**: 
   - 지정 조건 충족 시 특정 애플리케이션 실행, 설정된 타임라인에 맞춘 연속 단축키 입력, 텍스트 자동 붙여넣기, 시스템 명령어(종료, 삭제, 복사 등) 실행.

### 4.3. 브랜드 소개 페이지 (`Button_3` 선택 시)
- **우측 영역**: 로지텍 브랜드 레이아웃 및 셋업 관련 메인 브랜드 이미지 배치.
- **좌측 영역**: 로지텍의 브랜드 철학, 혁신적 사용자 경험(Logitech Options, FLOW, Smart Actions)에 대한 소개 문구 출력.
